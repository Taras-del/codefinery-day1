# Книга простих рецептів

Навчальний репозиторій для першого заняття з Git і GitHub. Тут можна побачити історію змін, створити гілку, запропонувати зміну та розв'язати конфлікт.

Відкрити на GitHub: https://github.com/YuraPas/coderefinery-nltu-recipes-ua

## Рецепти

- [Вівсяна каша](breakfast/porridge.md)
- [Фруктовий салат](salads/fruit-salad.md)
- [Млинці](desserts/pancakes.md)

## Початок роботи

1. Відкрийте цей репозиторій на GitHub.
2. Натисніть **Fork**, щоб створити власну копію у своєму обліковому записі.
3. Переконайтеся, що над назвою репозиторію вказано ваш обліковий запис.
4. Перегляньте файли та історію комітів у вашій копії.

Для вправ у браузері потрібен обліковий запис GitHub. Для локальної вправи потрібні Git та редактор тексту. Початковий стан позначено тегом **day1-start**.

## Вправи

### 1. Зміна та коміт

У власній копії відкрийте **breakfast/porridge.md**. Додайте до інгредієнтів рядок **- 30 г чорниці** та відповідний крок приготування. Збережіть зміну окремим комітом. Перегляньте різницю між версіями.

### 2. Гілка та запит на злиття

Створіть гілку **fruit-more-apples**. У файлі **salads/fruit-salad.md** замініть **- 1 яблуко** на **- 2 яблука**. Зробіть коміт. Відкрийте запит на злиття цієї гілки у **main вашої копії** та перегляньте вкладку змінених файлів. Злийте зміни у власну **main**.

### 3. Конфлікт

Почніть із рядка **- 2 банани** у **main** власної копії.

1. Створіть гілку **banana-three** від **main**.
2. У цій гілці замініть **- 2 банани** на **- 3 банани** та зробіть коміт.
3. Перейдіть у **main**, замініть той самий початковий рядок на **- 1 банан** та зробіть коміт.
4. Спробуйте злити **banana-three** у **main**. Дві гілки змінили один рядок, тому виникне конфлікт.
5. Узгодьте результат: залиште **- 2 банани**. Видаліть позначки конфлікту, позначте файл як розв'язаний та завершіть злиття.

### 4. Підготовлені та непідготовлені зміни

Склонуйте власну копію для локальної роботи. У **desserts/pancakes.md** змініть кількість молока з **200 мл** на **250 мл** і додайте файл до підготовлених змін. Потім у тому самому файлі змініть кількість борошна зі **150 г** на **170 г**, але ще не додавайте цю зміну. Порівняйте підготовлені та непідготовлені зміни. Перед комітом перевірте, яка саме версія до нього увійде.

### Додаткова вправа

Додайте власний рецепт до однієї з наявних папок. Використайте назву файлу латинськими літерами, а текст напишіть українською. Зробіть окремий коміт.
